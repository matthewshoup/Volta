# VOLTA
Polyphonic high-voltage analog synthesizer for macOS.

Rev 0.1:
- 12-voice polyphony
- dual saw VCOs plus sub oscillator
- oscillator detune
- resonant TPT low-pass VCF
- ADSR
- nonlinear tube-style drive
- transformer flux/saturation stage
- VOLTAGE macro for drift, filter instability and extra drive
- VST3, AU and Standalone universal macOS builds

This is the first playable engine. Planned: anti-aliased oscillators, oversampling, PWM/sync, LFOs, modulation matrix, unison and expanded filter modes.
